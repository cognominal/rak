# rak-docs

Documentation for rak readers: what rak is, how to use it, and where it comes from.
Terms are defined in [GLOSSARY.md](../GLOSSARY.md). The design documents, status and
open questions are in [rak-plans](../rak-plans/README.md).

## Using rak

- [rak](rak.md): what rak is and why.
- [Cheat sheet](CHEATSHEET.md): rak syntax at a glance. `CHEATSHEET.ans` is the same,
  highlighted for a terminal: `less -R rak-docs/CHEATSHEET.ans`.
- [irak tutorial](irak-tutorial.md), also in [French](irak-tutorial.fr.md) and
  [Russian](irak-tutorial.ru.md).
- [Demo recordings](demos/README.md): GIFs of irak, rebuilt with `make rak-demos`.

## Releases

- [0.0.1](releases/0.0.1.md): a pre-release, to try a packaged rak.

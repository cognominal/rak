# rak 0.0.1

A preview of [0.1](../../rak-plans/ROADMAP.md), the first planned release, to try a packaged,
installed rak. Expect rough edges: backward compatibility is not kept before 0.5.

rak is Rakudo with a second frontend: `.rak` files, and irak, the interactive shell,
get a lighter, shell-flavoured syntax; `.raku` files and modules stay plain Raku. See
[rak.md](../rak.md) for the idea, the [cheat sheet](../CHEATSHEET.md) for the syntax,
and the [architectural note](../../rak-plans/architectural-note.md) for how it differs
from Rakudo and what it depends on.

## What's in it

- naked strings, and juxtaposed words as arguments (`say hello world`);
- the `~` and `#` sigils, native `str` and `int` variables;
- dotty subscripts (`%h.users.1.name`, `->meth`);
- redirection to and from files, `.json` and `.jsonl` formats;
- URL targets: `<https://…` loads with GET, `> https://…` POSTs; bare hosts
  (`<api.github.com/…`);
- commands and pipelines, Unix and jq style, mixed; `$?` and `@?`;
- the formatter, a lone `.`;
- irak: the topic, `- ` to keep it, `!n` / `!!n` recall, paging long output, input
  highlighting, OSC 133 prompt marks, a web log in `@*IWEB`.

Known gaps are listed in [status.md](../../rak-plans/status.md).

## Built on

- Rakudo main 8e36510f59 (2026.11 plus later commits), RakuAST frontend;
- NQP 2026.11-12-g5fbb82e9a and MoarVM 2026.11-21-gfbae51aca;
- Terminal::LineEditor 0.0.23, patched, for irak's line editing.

## Installing

`rak-0.0.1.tar.gz`, attached to the release, holds everything the build needs, with
no network access. On Arch, from a rak checkout:

```sh
cd packaging/aur/rak && makepkg -si
```

Elsewhere, see [Building from the tarball](../../rak-plans/build/release.md#building-from-the-tarball).
Run `rak` for irak, or `rak file.rak`.
